# 2D Development

This section is for 2D-specific Godot APIs and workflows, such as `Area2D`, `CharacterBody2D`, `Vector2`, `Camera2D`, sprites, and 2D physics.

Shared ideas belong in [Foundations](/foundations/). A 2D page links back to those foundations instead of duplicating them.

## Start with these building blocks

- [Area2D](./area2d.md) — detect overlap-based gameplay interactions.
- [Collision layers and masks](./collision-layers-and-masks.md) — decide which objects can detect each other.
- [Vector2 movement](./vector2-movement.md) — use vectors for direction, movement, and facing.
- [Screen wrapping](./screen-wrapping.md) — wrap an object around a rectangular viewport.
