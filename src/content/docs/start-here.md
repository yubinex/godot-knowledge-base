# How to use this knowledge base

## When you are blocked

Use the site search with the word you know: a Godot class (`Area3D`), an action (“connect signals”), or a goal (“make a pickup”). Pages are named and described for these searches.

## Choose the right page type

- **Foundations** explain a shared idea, such as signals or timers.
- **2D** and **3D** pages explain APIs and workflows that differ by dimension.
- **Patterns** show how to build a specific feature and list what you need to understand first.

## Follow prerequisites

If a pattern lists prerequisites you do not know, open those pages first. For example, a future pickup pattern may require an area node, collision filtering, signals, and groups.

## Use related pages intentionally

The **Related** section points to the most useful next topic. It is not a complete list; use search whenever you have a new question.

## Keep it growing well

When a course or project teaches something new, an agent should follow [the update contract](/contributing/knowledge-graph/). It merges repeated concepts into existing pages and adds separate 2D/3D pages only when Godot's APIs or workflow actually differ.
