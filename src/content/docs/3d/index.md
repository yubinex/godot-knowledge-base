# 3D Development

This section is for 3D-specific Godot APIs and workflows, such as `Area3D`, `CharacterBody3D`, `Vector3`, `Camera3D`, meshes, and 3D physics.

Shared ideas belong in [Foundations](/foundations/). A 3D page links back to those foundations instead of creating duplicated “3D” versions of shared concepts.
