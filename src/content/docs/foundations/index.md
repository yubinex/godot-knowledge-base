# Foundations

This section contains concepts that remain the same across 2D and 3D projects. Start here when you need to understand a Godot building block before using it in a specific game feature.

## Start with these building blocks

- [Signals](./signals.md) — react to events without tightly coupling nodes.
- [Scene lifecycle](./scene-lifecycle.md) — decide where setup and per-frame logic belong.
- [Input actions](./input-actions.md) — write controls that are independent of specific keys.
- [Groups](./groups.md) — label nodes by gameplay role.
- [Timers](./timers.md) — run work after a delay or at intervals.
- [Instantiating scenes](./instantiating-scenes.md) — create reusable scene instances at runtime.
- [Scripts and node behavior](./scripts-and-node-behavior.md) — give a node reusable behavior with GDScript.
- [Tweens](./tweens.md) — animate properties in code.
- [Removing nodes safely](./removing-nodes-safely.md) — remove an object during gameplay.
